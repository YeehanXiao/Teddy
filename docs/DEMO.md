# TEDDY demo

This directory provides a minimal demo dataset for quickly testing the
core TEDDY workflow.

## Contents

- `data/`: a small mm10/GRCm38 demo dataset (chr8 subset), including:
  - reference GTF
  - TE annotation
  - two RNA-seq BAM files
- `run_demo.R`: runs the complete short-read TEDDY workflow on the demo
  dataset.
- `output/`: expected output generated by `run_demo.R`.

## Usage

From the TEDDY repository root, run:

``` bash
Rscript demo/run_demo.R
```

The script reproduces the expected demo output in `demo/output`.

For a complete description of all functions, parameters, and advanced
workflows (including long-read and cross-platform analyses), please
refer to the TEDDY tutorial and package vignettes.
