# Pick the most expressed reference transcript for a gene

Selects the highest-expressed reference transcript for a given gene from
a \`SummarizedExperiment\` object generated by \`stringtieCombine()\`.

## Usage

``` r
pick_canonical_tx(
  combineSE,
  gene,
  assay_name = "FPKM",
  samples = NULL,
  ref_tx_pattern = "^ENS"
)
```

## Arguments

- combineSE:

  A \`SummarizedExperiment\` object generated by \`stringtieCombine()\`.

- gene:

  Character. Gene name to query.

- assay_name:

  Character. Assay used for ranking. Default is \`"FPKM"\`.

- samples:

  Optional character or integer vector. Samples/columns used for
  expression ranking. If \`NULL\`, all columns are used.

- ref_tx_pattern:

  Optional regular expression used to restrict reference transcript IDs.
  Default is \`"^ENS"\`. Set to \`NULL\` to disable this filter.

## Value

A character scalar transcript ID. Returns \`NA_character\_\` if no match
is found.
