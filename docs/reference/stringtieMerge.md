# R wrapper to Run stringtie tool

Merge transcripts

## Usage

``` r
stringtieMerge(reference, gtfFiles, outfile, params = "")
```

## Arguments

- reference:

  Use a reference annotation file to guide assembly process

- gtfFiles:

  Character, GTF files assembled from transcripts by stringtie

- outfile:

  Character, the output of the merged GTF

- params:

  Other parameters
