# Plot Isoform Expression Dynamics

Plot the expression dynamics of isoforms across different developmental
samples or conditions.

## Usage

``` r
plotIsoformDynamics(
  combineSE,
  txid,
  gene_name = NULL,
  assay_name = "FPKM",
  group = NULL,
  group_order = NULL,
  ratio = FALSE,
  cols = NULL,
  main = NULL,
  ylab = NULL,
  lwd = 1.2,
  pch_size = 3
)
```

## Arguments

- combineSE:

  A \`SummarizedExperiment\` object generated by \`stringtieCombine()\`.

- txid:

  Character vector. Transcript IDs to plot.

- gene_name:

  Optional character. Gene name shown in the plot title.

- assay_name:

  Character. Assay to use. Default is \`"FPKM"\`.

- group:

  Optional character vector used to average samples by group/stage.
  Length must match the number of columns in the assay matrix.

- group_order:

  Optional character vector specifying plotting order of groups.

- ratio:

  Logical. If TRUE, plot expression ratio among selected transcripts.

- cols:

  Optional color vector for transcript lines. Can be named by transcript
  ID.

- main:

  Optional plot title. If \`NULL\`, generated from \`gene_name\`.

- ylab:

  Optional y-axis label.

- lwd:

  Line width.

- pch:

  Point type.

- ...:

  Additional arguments passed to \`plot()\`.

## Value

Invisibly returns the matrix used for plotting.
