# Pick TE-chimeric transcript(s) for a gene

Selects TE-chimeric transcript(s) associated with a given gene. Input
can be either a precomputed \`chi_GTF\` from \`processGTF()\` or a
\`combineSE\` object together with TE annotation. If expression data are
provided through \`expr\` or \`combineSE\`, matched transcripts are
ranked by mean expression.

## Usage

``` r
pick_chimeric_tx(
  gene,
  chi_GTF = NULL,
  combineSE = NULL,
  te = NULL,
  gene_col = "gene_name",
  assay_name = "FPKM",
  expr = NULL,
  samples = NULL,
  return_all = FALSE,
  minoverlap = 5,
  threads = 8
)
```

## Arguments

- gene:

  Character. Gene name or gene ID to query.

- chi_GTF:

  Optional \`GRanges\` object generated by \`processGTF()\`.

- combineSE:

  Optional \`SummarizedExperiment\` generated by \`stringtieCombine()\`.

- te:

  Optional \`GRanges\` TE annotation. Required when \`combineSE\` is
  used and \`chi_GTF\` is not provided.

- gene_col:

  Character. Column used for gene matching. Default is \`"gene_name"\`.

- assay_name:

  Character. Assay used for expression ranking when \`combineSE\` is
  provided. Default is \`"FPKM"\`.

- expr:

  Optional expression matrix used for ranking chimeric transcripts. Rows
  should be transcript IDs and columns should be samples.

- samples:

  Optional character or integer vector. Samples/columns used for
  expression ranking. If \`NULL\`, all columns are used.

- return_all:

  Logical. Whether to return all matched transcript IDs.

- minoverlap:

  Integer. Minimum overlap passed to \`processGTF()\`.

- threads:

  Integer. Number of threads passed to \`processGTF()\`.

## Value

A character vector of transcript ID(s), or \`NA_character\_\`.
